## 📦 Featured Project

### [Tana Stock](https://github.com/sknpz/tana-stock)

A fullstack inventory management system: vanilla JavaScript front-end and a **Java 21 + Spring Boot** REST API backed by **PostgreSQL**.

* JWT authentication with Spring Security
* Versioned database migrations with Flyway
* Unit and integration tests with JUnit 5 and Testcontainers
* CI with GitHub Actions on every push and pull request
* Dockerized API deployed on Render, database on Supabase, front-end on GitHub Pages

[**Live demo**](https://sknpz.github.io/tana-stock/) · [API documentation](https://tana-stock-api.onrender.com/swagger-ui.html) · [Source code](https://github.com/sknpz/tana-stock)
